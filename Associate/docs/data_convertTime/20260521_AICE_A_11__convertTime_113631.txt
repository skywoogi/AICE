퓨처 엔지니어링이란 모델의 정확도를 높이기 위해서 주어진 데이터를 잘 표현할 수 있는 퓨처로 변형시키는 과정이며 데이터의 도매인 지식을 활용해서 퓨처를 만드는 과정이라고 이해해 주시면 되겠습니다
여기서 퓨처는 각 데이터의 특징을 나타내는 말로써 우리가 앞서 변수, 컬럼이라고 했던 것들을 지칭한다고 생각하시면 됩니다
모델의 성능을 높이기 위해서 하이퍼 파라미터 튜닝이나 여러 가지 모델을 만들어 모델의 성능을 높이기 위해서 높은 모델을 찾으려고 합니다
이런 방법보다는 퓨처 엔지니어링을 통해서 기존 퓨처를 변형하거나 새로운 퓨처를 만들어 획기적인 성능을 높일 수도 있습니다
퓨처 엔지니어링에 대한 확실히 배워서 활용해 주시면 좋겠습니다

비닝이란 연속형 변수를 범주형 변수로 만드는 방법입니다
연속형 변수를 적절히 그룹으로 지어주면 범주형으로 데이터를 표현하기에 좀 더 데이터를 이해하기 쉬워질 수가 있습니다
대표적인 예시를 드려보면 나이를 가지고 10대, 20대, 30대로 구분짓는 경우가 비닝이 될 수 있고요 수능 성적을 가지고 그 등급으로 나누어 수능 등급을 결정하는 방법도 대표적인 비닝의 사례가 되겠습니다

큐커트는 구간의 개수를 지정을 해서 구간의 동일한 개수가 포함되도록 구간 개수만큼 구간을 나누게 됩니다
예를 들어 1부터 9까지의 숫자를 가지고 커트와 큐커트로 나눈다고 볼 때 커트는 이렇게 1부터 2, 3부터 6, 7부터 6 해서 원하는 구간으로 나눠서 3개의 구간을 만들 수 있었습니다
그런데 큐커트의 같은 경우 원하는 구간 개수를 입력하면 구간 개수 3개겠죠? 3개를 입력하게 되면 자기가 알아서 똑같은 개수가 들어갈 수 있도록 1부터 3까지, 4부터 6까지, 7부터 9까지 해서 똑같은 개수가 들어가게끔 해서 동일한 개수가 들어가서 구간을 나눠주는 것을 알 수가 있습니다

스케일링은 숫자 데이터 간의 상대적 크기 차이를 제거하는 방법입니다
AI 모델링에서는 각 컬럼에 들어있는 데이터의 상대적인 크기에 따라 데이터 분석이나 모델링 결과가 달라지게 됩니다
예를 들어 1부터 1000까지의 값을 가지는 변수 a와 1부터 10까지의 값을 가지는 변수 b가 있다고 가정을 해보면 데이터 분석을 수행하게 되면 상대적으로 큰 숫자를 가지는 a 변수에 더 큰 영향을 미치게 됩니다
따라서 숫자 데이터는 상대적 숫자 크기를 제거할 필요가 있고 우리는 이를 스케일링이라고 합니다
스케일링 방법에는 여러 가지가 있는데 여기서는 스탠다드 스케일러하고 로봇 스케일러에 대해서 알아보겠습니다
첫 번째 스탠다드 스케일러는 각 특성의 평균을 0으로 분산을 1로 해서 정규 분포를 만들어 상대적인 숫자 크기를 제거하게 됩니다
그리고 로봇 스케일러는 평균과 분산 대비 대신에 중간 값과 4분위 값을 사용하여 상대적인 숫자 크기를 제거할 수 있으며 전체 데이터와 아주 동떨어진 이상치 데이터의 영향을 덜 받게 됩니다
다른 스케일링 방법으로 각 특성이 0과 1 사이에 위치하도록 만드는 밋맥스 스케일러가 있습니다
밋맥스 스케일러를 사용하게 되면 모든 데이터가 0과 1 사이의 값으로 범위가 조정되기 때문에 만약 아주 큰 이상치가 있을 경우 변환된 값이 대부분 앞쪽 좁은 범위로 압축이 되고 이상치가 1에 위치하게 되어 스케일링 왜곡이 될 수 있기에 이상치가 있는 경우 주의해서 사용하셔야 합니다
맥스 앱솔루트 스케일러는 각 특성의 절대 값이 0과 1 사이가 되도록 스케일링 합니다
즉 모든 값이 마이너스 1과 1 사이로 표현이 되며 데이터가 양수일 경우 밋맥스 스케일러와 동일하게 작용하게 됩니다

라벨 인코딩은 범주형 변수의 문자열 값을 숫자로 맵핑합니다
왜 이런 작업이 필요한 이유는 컴퓨터는 0과 1 숫자를 잘 이해하지만 문자열 데이터, 남자, 여자 등은 이해하지 못합니다
그래서 컴퓨터가 잘 데이터를 이해할 수 있도록 숫자로 바꾸는 작업이 필요하며 우리는 라벨 인코딩을 통해 수행하시면 되겠습니다
화면의 예시처럼 남자는 1로, 여자는 2로 이렇게 숫자로 바꾸는 과정을 라벨 인코딩이라고 하며 여러 가지 방법으로 라벨 인코딩을 수행할 수 있으며 실습에서 같이 확인해 보도록 하겠습니다
모델링을 위한 퓨처 엔지니어에서 유용하게 사용되는 기능 중에 하나가 원핫 인코딩입니다
원핫 인코딩은 하나의 데이터만 1로 만들고 나머지 데이터는 0으로 만들어주는 방법입니다

그래서 서울 같은 데이터가 있을 경우에는 서울만 1이 되고 그 다음에 나머지는 0, 0으로 채우게 됩니다
대전의 같은 경우에는 이렇게 대전만 1이 되고 나머지를 0, 0으로 채우게 됩니다
마찬가지로 부산은 부산만 1이 되고 나머지 0, 0으로 채울 수가 있게 됩니다
이런 식으로 해서 각각의 우리가 라벨 인코딩을 해주었는데 얘들이 같은 레벨에서 동등한 입장에서 데이터를 볼 수 있도록 원한 인코딩 변환을 해 보았습니다
이렇게 해서 1개의 컬럼이 3개의 컬럼으로 바뀌게 되는 점이 있었고 그리고 하나만 핫하고 나머지는 0으로 이렇게 표현을 하게 됩니다
우리는 앞페이지에서 범주형 데이터의 값들을 컴퓨터가 이해할 수 있는 숫자 형태로 변경하고 그리고 해당 값들이 높고 낮음이 없이 똑같은 수준에서 볼 수 있도록 1개의 컬럼이 여러 개의 컬럼으로 변형하고 1개의 값만 1로 나머지는 0으로 채워지는 원핫 인코딩을 배웠습니다
원핫 인코딩을 판다스의 getDummies 함수를 활용하면 쉽게 원핫 인코딩을 수행할 수 있습니다
