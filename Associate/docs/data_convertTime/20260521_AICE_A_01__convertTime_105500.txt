이번에는 AI 학습 원리에 대해 알아보겠습니다
먼저 AI 모델 목표가 뭘까요? 모델에 입력을 넣었을 때의 모델의 예측각과 정답을 일치하도록 만드는 것입니다
머신러닝의 목표나 딥러닝의 목표는 동일하며 최대한 모델의 예측각과 정답을 일치시키도록 하는 것입니다
우리는 앞에서 모델의 예측각과 정답을 최대한 일치시키는 것이 AI 모델의 목표라는 것을 배웠습니다
그럼 이 목표를 위해서 얼마나 잘 일치시킬지를 확인하기 위해서 예측각과 정답의 차이를 계산할 수 있으며 이 차이를 코스트 로스 에러라고 합니다
이렇듯이 코스트 비용을 계산해 주는 함수가 있는데 이를 코스트 펑션 비용 함수라고 합니다
우리는 비용 함수를 이용해서 예측각과 정답과의 차이가 얼마가 나고 있는지 모델의 비용이 얼마인지를 확인할 수가 있습니다
이번엔 옵티마이저입니다
우리는 AI 모델의 목표는 예측각과 정답을 일치시키는 것이라고 배웠습니다
예측각과 정답을 일치가 될수록 비용은 0에 가까워지며 최소 비용이 됩니다
결국 최소 비용의 모델을 만들기 위해서 코스트가 비용이 점점 줄이는 방향으로 비용이 점점 줄이는 방향으로 모델의 파라미터를 업데이트하면서 학습을 진행합니다
이렇게 비용이 최소화되는 최적의 모델을 만들 수 있도록 도와주는 것이 최적화 알고리즘 옵티마이저가 되겠습니다
AI 모델의 학습 원리에 대해 정리해 보겠습니다
AI 모델의 목표는 모델에서 나온 예측각과 정답을 일치시키는 것입니다
이를 위해 모델의 예측각과 정답이 얼마나 잘 맞는지 비용함수를 통해서 모델의 비용을 구할 수 있습니다
우리의 목표는 예측각과 정답이 일치하도록 만드는 것인데 이럴 경우 모델의 비용이 최소화됩니다
즉, 모델의 비용이 최소화되므로 우리는 최적화 알고리즘 옵티마이저를 활용해서 비용이 최소인 최적의 모델을 만들 수 있으며 이를 통해 우리의 목표인 정답과 예측각을 일치하도록 할 수가 있습니다
이번에는 AI 모델링 순서에 대해서 알아보겠습니다
AI 모델링 하는 순서에 대해 전반적으로 살펴보겠습니다
먼저 모델링 하기 위해서는 첫 번째로 데이터가 없으면 AI도 학습시킬 수 없으므로 반드시 데이터가 있어야 하며 데이터를 잘 모아서 수집해야 합니다
그 다음 수집된 데이터를 정리를 해야 합니다
컴퓨터는 0, 1 숫자만 잘 이해하고 문자의 데이터는 잘 모르기에 컴퓨터가 잘 이해할 수 있도록 0, 1 숫자로 표현해야 하며 결측치 데이터, 이상치 데이터 등들도 처리해 주어야 합니다
그래야만 모델 성능이 잘 나올 수 있습니다
그래서 모델링 하는 과정 중에서 대부분의 60%내지 70% 정도를 데이터 수집과 데이터 정리하는 데 노력과 시간이 소요하게 되며 나머지 30%내지 40% 정도는 모델 만드는 데 사용하게 됩니다
데이터를 수집하고 처리하는 데 더 많은 시간과 노력이 소요된다는 점을 이해해 주시기 바랍니다
그 다음에 잘 정리된 데이터를 트레인하고 테스트 데이터 세트로 나누고 테스트 데이터 세트는 장롱에 꼭 넣고 보지 않도록 하고 트레인 데이터 세트로 모델에게 주어서 모델 학습을 수행하게 됩니다
학습이 끝난 후에 모델이 배포 가능한지 성능이 잘 나오는지 확인하기 위해서 장롱 속에 있던 테스트 데이터 세트를 가지고 모델을 테스트하게 됩니다
만약 모델의 테스트 데이터 세트를 가지고 성능이 잘 나온다면 우리는 모델을 배포할 수가 있게 되고요
만약에 성능이 잘 나오지 않는다면 다시 뒤로 가서 다시 하이퍼 파라미터 튜닝이나 퓨처 엔지니어링 등을 통해서 모델을 다시 학습해서 성능을 높여야 되겠습니다
전반적으로 이런 AI 모델링 순서로 진행된다는 것을 이해해 주시면 되겠습니다
이번에는 핫 트렌드인 생성형 AI에 대해서 알아보도록 하겠습니다
먼저 생성형 AI에 대해 정의를 살펴보면 생성형 AI는 프로폰트에 대응하여 텍스트, 이미지, 기타, 미디어를 생성할 수 있는 일종의 인공지능 시스템이라고 나무위키에 나와 있습니다
생성형 AI의 대표적 모델은 바로 채집비티이며 채집비티는 대규모 텍스트를 훈련하여 콘텐츠를 생성하는 대규모 언어모델 LLM이 되겠습니다
채집비티는 5일 만에 이용자가 100만 명이 넘었고 40일 만에 천만 명이 가입했으며 또 두 달 만에 1억 명을 훌쩍 넘는 기록을 세우며 생성형 AI 열풍을 불게 만들었습니다
여러 산업 방면에서 활약 중인 생성형 AI에 대해서 알아보겠습니다
교육, 제조, 유통, 업무, 날씨, 금융 등 거의 모든 분야에서 생성형 AI를 활용하고 있습니다
일례로 생성형 AI 도입은 제조 산업에서 새로운 혁신을 예고하고 있습니다
최근 제조 현장에서는 결함 관리를 위한 산업용 AI 솔루션과 플랫폼 도입이 늘고 있으며 제품 제조 중 결함 탐지에 AI가 투입되거나 이름을 붙이는 이미지 라벨링 개선으로 획기적인 생산성 향상을 이루고 있습니다
맥킨지 보고서에 따르면 2030년까지 AI로 창출되는 경제적 가치가 13조 달러에 달할 것이며 이 중 50%가 제조 및 산업 분야에서 나올 것이라고 전망합니다
생산 현장에서는 AI가 단순 작업을 대체하거나 스스로 문제를 해결해 생산성을 높이는 데 활용되고 있으며 오히려 사용하지 않는 산업 분야를 찾아보기 어려운 실정이 되겠습니다
그럼 생성형 AI에 대해 좀 더 알아보도록 하겠습니다
우리가 알고 있는 Chats GPT도 하나의 LLM이라고 보시면 되겠습니다
LLM은 Large Language Model의 약자로 초고대 언어 모델을 뜻합니다
저희는 Chats GPT를 활용해서 언어 번역, 텍스트 생성, 텍스트 요약, 감정 분석, 질문을 하고 답변을 받을 수 있으며 텍스트를 주고 이미지나 동영상을 만들 수 있습니다
또한 LLM을 활용해서 챗봇이나 가상 비서, 교육, 의료 제조, 창작 영역에도 활용하게 될 수가 있습니다
LLM, Large Language Model의 종류에 대해서 알아보겠습니다
우리가 제일 잘 알고 있는 OpenAI의 Chats GPT, 그리고 마이크로소프트의 Bing, 구글의 Gemini, 메타의 Lama, 네이버의 HyperClover X 등 굉장히 많은 LLM, 초거대 언어 모델이 많이 존재하고 있으며 경쟁적으로 초거대 언어를 만들고 있습니다
Chats GPT로 많은 회사에서 활용 중에 있습니다

다만 Chats GPT가 외부 클라우드에 존재해서 사내 지식이 외부로 유출되는 보안 이슈가 문제가 발생하고 있습니다
이런 문제를 해결하자 나온 것이 Private LLM이 되겠습니다
상업적으로 오픈된 초거대 언어 모델을 활용하여 기업이 내부 데이터를 학습시켜 사내에서만 사용할 수 있도록 만든 것이 Private LLM이 되겠습니다
Private LLM 모델의 경우 정보 유출 없이 사내 내부에서만 사용하여 보안성을 높이고 작은 모델 사이즈로 비용 측면에서도 각광받으며 차세대 생성형 AI 시장 대세론을 타고 있습니다
